# Trois Accords

Appli web pour apprendre la guitare avec des morceaux connus et des comptines : parcours en 14 étapes, accompagnement (voix, guitare, basse, batterie, piano), exercices, tablatures.

## Installer sur le téléphone

- **iPhone (Safari)** : ouvre le lien, touche Partager, puis « Sur l'écran d'accueil ».
- **Android (Chrome)** : ouvre le lien, menu ⋮, puis « Installer l'application ».

L'appli fonctionne ensuite hors ligne. La progression est enregistrée sur le téléphone.
